> I am taking the Thanksgiving weekend of 26 to 29 November 2026 to put this account in order: to keep what I will maintain and to archive the rest as dated editions. Thank you to everyone who has read this work and sent feedback, on LinkedIn, on GitHub and otherwise. It shaped what stays.

One person cannot keep twenty-three repositories correct. A repository that looks maintained and is not misleads its reader, and one that says plainly that it has stopped does not.

## The fact

Every repository in this account is in one of three tiers from 26 November 2026 (KST).

- **Developed.** New work is being added.
- **Maintained.** Kept correct, with no new work planned. It is checked on the first Monday of each month, and an error of law, or anything else that would mislead a reader, is corrected on the day it is found.
- **Archived.** A dated edition. The repository is read-only on GitHub from the date in the table and receives no corrections, legal ones included: a reader verifies every statement of law, regulation or standard against a current primary source before relying on it.

Nothing was deleted, merged, renamed or moved, so every link into this account resolves as it did. Each license still applies, and [LICENSING.md](LICENSING.md) still covers every repository. Each archived repository opens with a banner that gives its edition date and the version to cite.

**This file is true as it stands.** The archiving is done over the weekend, one repository at a time. A row whose "Archived on" cell is empty is a repository not yet archived; the cell is filled in when it is.

## The instruments

Scheduled acceptance testing ended on 26 November 2026. Each instrument's status in [ECOSYSTEM.md](ECOSYSTEM.md#instrument-status) is its last test, with the run, the date and the model, and it stays as it reads: no "Not accepted" was removed or softened for the archive. An archived instrument is never run again. An instrument in a maintained repository changes only with a run logged that day under [ACCEPTANCE.md](ACCEPTANCE.md). Run transcripts stay where they are in each archived repository, frozen at its final release.

## What is no longer checked

2. Whether a prompt still behaves as its last test says. No suite runs on a schedule.
3. A maintained repository between two monthly checks, except for the dated legal checks in [CURRENCY.md](https://github.com/rolldabones/ai-governance-for-boards/blob/main/CURRENCY.md), which keep their own dates.
4. The Korean, Vietnamese and Japanese text of the Slow AI Kitchen application, as before.

## How a decision is reversed

A repository leaves the archive by being unarchived on GitHub, followed by a release that removes its banner and a dated line in this file. A maintained repository is archived the same way in reverse: a final release with the banner, then the archive. This arrangement is reviewed on 22 February 2027.
