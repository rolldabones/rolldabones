## The fact

Seven repositories in this account were published as companions to custom GPTs built by the author on the OpenAI platform. **Each of the seven GPTs was retired on 1 October 2026 (KST) and converted to a private plug-in on the OpenAI platform.** The plug-ins are private and not publicly listed; no repository mirrors them or makes any claim about what they run. The instructions published in each repository are the text of record, and they suffice for anyone who wants to build their own: paste them as the system prompt, custom instructions or project instructions of any current assistant.

## What changed in the repositories

1. **Mirror claims became history.** "Verbatim as deployed" and every sentence of the same kind now read "as last verified on <date>, before the conversion".
2. **The links were struck.** The public `chatgpt.com/g/` addresses no longer appear as live links; the shipped changelogs keep them as history.
3. **The instructions became instruments.** From 1 October 2026 each instruction block is an ordinary instrument of its repository, edited and versioned under that repository's own rule. GPT-only dependencies (conversation starters, capability toggles, attached knowledge files, the builder's character ceiling) were removed or recast so that each block runs on its own; the configuration as last deployed is archived in each repository's CHANGELOG.
4. **Change control has a named successor.** Each GPT configuration is Locked as of 1 October 2026. Every change-control sentence that pointed at the GPT now points at its successor: the published instructions run as a system prompt on any current frontier model, with one logged run recorded in the repository's `tests.md` before a changed block is accepted.
